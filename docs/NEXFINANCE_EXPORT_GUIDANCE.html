Panduan Export PDF Laporan Keuangan

Dokumen ini membantu operator, bendahara, dan admin memahami alur penggunaan tombol Unduh PDF pada modul Laporan agar hasil dokumen tetap rapi, konsisten, dan siap dibagikan ke stakeholder.

Dokumen Panduan Export PDF
Modul Laporan Keuangan
Audience Admin • Bendahara • Pimpinan

Tujuan fitur

Export PDF digunakan untuk menghasilkan dokumen ringkas namun presentable dari data laporan keuangan tahunan. Hasil PDF dapat dipakai untuk rapat internal, pelaporan pimpinan, dokumentasi audit, atau dibagikan ke pihak yang membutuhkan versi read-only.

Yang akan ikut dalam PDF

  • Ringkasan KPI utama pendapatan, beban, surplus, dan margin.
  • Laporan laba rugi dan komponen pendapatan/beban.
  • Rekap tren bulanan untuk memudahkan pembacaan performa.
  • Neraca ringkas yang menampilkan aset, kewajiban, dan ekuitas.

Keunggulan format baru

  • Tampilan lebih bersih dan konsisten dengan identitas NexFinance.
  • Warna ringkas tetap mengikuti tone teal/navy yang sudah dipakai sistem.
  • Layout ramah dibaca di layar maupun saat dicetak.
  • File langsung terunduh tanpa butuh proses manual tambahan.

Langkah penggunaan

  1. Buka menu Laporan dari sidebar NexFinance.
  2. Pilih tab laporan yang ingin difokuskan: Laba Rugi, Neraca, atau Tren Bulanan.
  3. Klik tombol Unduh PDF di kanan atas halaman.
  4. Tunggu sistem menyusun dokumen, lalu file PDF otomatis terunduh ke perangkat.
  5. Buka file hasil download untuk memastikan nama file, angka, dan periode sudah sesuai.

Tips operasional

  • Gunakan desktop/laptop saat akan mengirim PDF resmi ke pimpinan atau eksternal.
  • Sebelum export, pastikan user berada di jaringan stabil agar proses download tidak terputus.
  • Jika angka laporan berubah, lakukan export ulang agar file yang dibagikan selalu versi terbaru.

Troubleshooting singkat

PDF tidak terunduh

Periksa apakah browser memblokir download otomatis atau ada popup/download permission yang belum diizinkan.

Isi terlihat tidak sesuai

Refresh halaman laporan, pastikan data terbaru sudah muncul di layar, lalu lakukan export ulang.

File sulit dibagikan

Gunakan nama file bawaan sistem karena sudah rapi dan mudah dikenali berdasarkan modul laporan dan tahun.

Butuh bantuan tambahan

Gunakan tombol Panduan PDF di halaman laporan untuk membuka dokumen ini kapan saja.
