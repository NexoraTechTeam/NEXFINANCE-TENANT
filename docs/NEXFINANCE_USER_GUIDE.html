Tentang NexFinance

💡 NexFinance adalah sistem manajemen keuangan terintegrasi yang dirancang khusus untuk kebutuhan Sekolah Islam Terpadu, mengimplementasikan standar pelaporan yayasan ISAK 35.

Latar Belakang

Dalam upaya meningkatkan transparansi, efisiensi, dan akuntabilitas pengelolaan keuangan, Yayasan Almusabbihin membutuhkan sistem digital yang mampu mengelola seluruh proses keuangan secara real-time, otomatis, dan sesuai standar pelaporan yayasan.

NexFinance dikembangkan oleh PT Alfarhein Teknologi Investama (Nexora) sebagai solusi komprehensif yang mencakup 7 modul utama.

Cara Login

  1. Buka browser dan akses finance.almusabbihin.sch.id (atau http://localhost:3000 untuk pengembangan lokal)

Modul Penagihan SPP

Modul SPP (Sumbangan Pembinaan Pendidikan) mengelola seluruh proses penagihan, pembayaran, dan pelaporan iuran siswa.

Membuat Invoice SPP

  1. Navigasi ke menu SPP dari navbar
  2. Klik tombol "Buat Invoice"
  3. Isi form: Student ID, Nama Siswa, Kelas, Jumlah, Bulan
  4. Klik "Simpan" — invoice otomatis dibuat dengan due date 5 hari ke depan

Mencatat Pembayaran

  1. Temukan invoice di daftar (filter: "Belum Bayar")
  2. Klik tombol "Bayar" pada baris invoice
  3. Konfirmasi jumlah dan metode pembayaran (Transfer / Tunai)
  4. Status invoice berubah menjadi Lunas

Status Invoice

StatusKeteranganAksi Tersedia
Belum BayarInvoice dibuat, menunggu pembayaranBayar, Edit
LunasPembayaran telah diterima dan dikonfirmasiCetak Bukti
TerlambatMelewati tanggal jatuh tempoBayar, Kirim Reminder

Laporan SPP

Laporan tersedia melalui endpoint /spp/reports dan menampilkan:

  • Total invoice yang diterbitkan
  • Total pembayaran yang diterima
  • Collection rate (%)
  • Total siswa aktif
✅ Target Optimal: Collection rate SPP ≥ 90% per bulan menunjukkan performa penagihan yang baik.

Modul Penggajian (Payroll)

Modul Penggajian mengelola perhitungan gaji karyawan secara otomatis termasuk PPh 21 TER, BPJS Kesehatan, dan BPJS Ketenagakerjaan.

Komponen Gaji

KomponenTipeKeterangan
Gaji PokokPenghasilanGaji dasar sesuai jabatan
Tunjangan SertifikasiPenghasilanTunjangan profesi guru (≈1× gaji pokok)
Tunjangan KeluargaPenghasilanTunjangan istri/suami dan anak
BPJS KesehatanPotongan1% dari gaji bruto (ditanggung karyawan)
BPJS KetenagakerjaanPotongan5.7% dari gaji bruto (JHT 2% + JP 1% + JKK 0.24% + JKM 0.3% + JHT EL 3.7%)
PPh 21 TERPotongan5% dari gaji bruto (tarif efektif rata-rata)

Cara Menghitung Gaji

  1. Navigasi ke menu Penggajian
  2. Klik tombol "Hitung Baru"
  3. Pilih Karyawan dari dropdown dan tentukan Bulan
  4. Klik "Hitung Gaji" — sistem menghitung otomatis semua komponen
  5. Slip gaji muncul dengan rincian lengkap. Klik "Cetak Slip" bila diperlukan

Formula Perhitungan

// Komponen Gaji Gaji Bruto = Gaji Pokok + T.Sertifikasi + T.Keluarga BPJS Kes = Gaji Bruto × 1% BPJS TK = Gaji Bruto × 5.7% (JHT+JP+JKK+JKM) PPh 21 TER = Gaji Bruto × 5% (Tarif Efektif Rata-rata) Gaji Bersih = Gaji Bruto - BPJS Kes - BPJS TK - PPh 21
⚠️ Catatan Pajak: Tarif PPh 21 TER (5%) adalah tarif default. Untuk karyawan dengan PTKP berbeda, konsultasikan dengan bagian akuntansi untuk penyesuaian tarif.

Kategori Pengeluaran

  • 📎 ATK & Supplies — Alat tulis kantor, kertas, toner
  • ⚙️ Operasional — Kebutuhan operasional harian
  • 🔧 Pemeliharaan — Perbaikan gedung, peralatan
  • 🚗 Transportasi — Perjalanan dinas, bensin
  • 🍱 Konsumsi — Rapat, acara sekolah
  • 💡 Utilitas — Listrik, air, internet
  • 📦 Lain-lain — Pengeluaran di luar kategori

Cara Mengajukan Pengeluaran

  1. Klik menu Pengeluaran → tombol "Ajukan Pengeluaran"
  2. Isi Deskripsi pengeluaran secara jelas dan detail
  3. Masukkan Jumlah (dalam Rupiah) dan pilih Kategori
  4. Klik "Ajukan" — status menjadi Menunggu

Cara Menyetujui Pengeluaran

  1. Buka daftar pengeluaran, filter "Menunggu"
  2. Review deskripsi dan jumlah pengeluaran
  3. Klik "Setujui" (hijau) atau "Tolak" (merah)
  4. Setelah 2 approval, status berubah menjadi Disetujui

Modul Pengadaan mengotomasi alur pengadaan barang/jasa dari permintaan hingga penerimaan dengan kontrol anggaran yang ketat.

Purchase Request (PR)

PR adalah permintaan internal untuk pengadaan barang/jasa sebelum PO diterbitkan ke vendor.

  1. Klik tab Purchase Request → "Buat PR"
  2. Isi: Deskripsi kebutuhan, Jumlah unit, Estimasi biaya, Tingkat urgensi
  3. PR tersimpan dengan status Menunggu dan ID unik (PR...)

Purchase Order (PO)

PO adalah dokumen resmi pemesanan yang dikirimkan ke vendor setelah PR disetujui.

  1. Klik tab Purchase Order → "Buat PO"
  2. Masukkan Referensi PR, Nama Vendor, Total Nilai PO
  3. PO dibuat dengan status Diterbitkan

Penerimaan Barang

  1. Setelah barang diterima secara fisik, temukan PO di daftar
  2. Klik "Terima Barang" pada PO terkait
  3. Status PO berubah ke Diterima — siap untuk proses pembayaran vendor
💡 Three-Way Matching: Sistem memastikan kecocokan antara PR (kebutuhan), PO (pesanan), dan penerimaan barang sebelum pembayaran dilakukan.

Modul Akuntansi ISAK 35

Modul Akuntansi mengimplementasikan standar ISAK 35 (Penyajian Laporan Keuangan Entitas Berorientasi Nonlaba) untuk yayasan pendidikan.

Tentang ISAK 35

ISAK 35 adalah interpretasi standar akuntansi yang mengatur penyajian laporan keuangan entitas nirlaba/yayasan di Indonesia. Perbedaan utama dari laporan bisnis komersial adalah klasifikasi dana: Dana Tidak Terikat (unrestricted) dan Dana Terikat (restricted).

Input Jurnal Umum

  1. Navigasi ke Akuntansi → tab "Jurnal Umum"

FAQ & Troubleshooting

Pertanyaan Umum

❓ Saya tidak bisa login. Apa yang harus dilakukan?

Pastikan (1) server backend berjalan di port 5000, (2) email dan password benar, (3) tidak ada kesalahan ketik. Jika lupa password, hubungi admin sistem di support@almusabbihin.sch.id.

❓ Data tidak muncul di halaman SPP / Pengeluaran?

Ini biasanya terjadi karena backend tidak berjalan. Cek status server dengan membuka http://localhost:5000/health. Jika error, jalankan ulang: npm run dev di folder backend.

❓ Laporan keuangan menampilkan angka yang sama setiap bulan?

Pada versi demo, data laporan menggunakan data statis representatif. Integrasi dengan database produksi akan menampilkan data real-time sesuai transaksi aktual.

❓ Bagaimana cara menghubungkan ke database PostgreSQL production?

Update variabel DATABASE_URL di file backend/.env dengan connection string PostgreSQL. Jalankan migrasi dengan npm run migrate.

❓ Apakah sistem bisa diakses dari mobile/tablet?

Ya. NexFinance didesain responsif. Untuk pengalaman terbaik gunakan layar ≥ 768px (tablet/desktop). Tampilan mobile telah dioptimasi.
